02 Featured project

Case study

Efteely إفتيلي

An Arabic Islamic Fatwa RAG assistant, built in three stages: from raw web pages to a grounded, production chatbot.

  1. 1

    Stage 1 · The Data

    51,000+ fatwas, scraped and cleaned

    Scraped and preprocessed 51,000+ fatwas from three sources (Bin Baz, IslamQA, IslamWeb) and published them as a public dataset on Kaggle.

    • Web Scraping
    • Pandas
    • Data Cleaning
    • Arabic NLP
    Dataset on Kaggle ↗
  2. 2

    Stage 2 · v1 Offline

    Fully local, privacy-first RAG

    CAMeL-Lab Arabic BERT embeddings (768-d), cosine-similarity top-5 retrieval, and a local Gemma 3 4B model via Ollama. No external APIs: everything runs on the machine.

    • CAMeL-BERT
    • Ollama
    • Gemma
    • RAG
    Code ↗
  3. 3

    Stage 3 · v2 Online Production

    Live on Hugging Face Spaces

    • ChromaDB retrieval with multilingual-e5 embeddings
    • LangChain chain with Llama 3.3 70B (Groq)
    • Answers grounded only in retrieved fatwas, with source links to the originals
    • Conversation-aware retrieval (last 6 turns)
    • LLM-based intent detection: chitchat vs. religious questions
    • LangChain
    • ChromaDB
    • multilingual-e5
    • Llama 3.3
    • Groq
